# CIFAR以外での検品データセット検証計画

## なぜ必要か

CIFAR-10に人工的な低品質画像を混ぜた実験は、提案手法の「効きそうな条件」を探すための予備実験である。
しかし、そのままでは「人工的に不利な画像を混ぜたから速くなっただけ」という弱い主張になる。

研究として主張するには、実際の検品に近いデータセットでも同じ構造が残るかを確認する必要がある。

## 第一候補: KolektorSDD

KolektorSDDは、実際の工業環境で撮影された電子部品表面の欠陥検出データセットである。
399枚中52枚が可視欠陥、347枚が正常であり、「多くは正常、少数が欠陥」という検品条件に近い。

今回の実験では、正常品を「通過」、欠陥品を「棄却」として扱う。
下側早期終了は、単に画像を分類するのではなく、「finalまで進めても信頼できる正常通過には戻らないか」を早い出口で予測する。

## 評価指標

- 誤通過: 欠陥画像を正常品として通すこと
- 良品ロス: finalなら信頼して通せた正常画像を早期に棄却すること
- 早期棄却率: finalを実行せずに下側出口で止めた割合
- 平均計算量: finalのみを1.0とした相対計算量

## 実験ジョブ

Colab GPUで `kolektor_late_recovery_001` を実行する。

出力:

- `results/kolektor_late_recovery_001_summary.json`
- `docs/kolektor_late_recovery_001.md`
- `results/kolektor_late_recovery_001.svg`

## 解釈方針

効果が出た場合:

CIFAR上の人工条件だけではなく、実工業表面欠陥データでも「後段に送っても信頼できる通過へ戻らない画像」を早期に止められる可能性がある。
この場合、FPGA上で下側出口の小さな判定器を追加し、後段回路の起動回数を減らす研究テーマとして進められる。

効果が弱い場合:

提案手法の効果は「入力品質が大きく崩れた画像が一定割合混ざる条件」に依存している可能性が高い。
その場合は、一般検品ではなく、屋外・農作物・搬送中ブレ・汚れ・部分欠損のように入力品質が揺れやすい検品タスクへ対象を絞る必要がある。
