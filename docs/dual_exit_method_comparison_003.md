# 両側早期終了 他手法比較

## 比較条件

- ラベルを出した画像だけの精度が 99.00% 以上
- finalのみと比べた平均計算量削減が 10.00% 以上
- 棄却は成功扱いにしない。ラベル出力率低下と良品ロスを同時に見る。
- 上側早期終了のみは、同じ99%級の精度制約を満たせる設定があるかで判定する。

## 結論

この条件では、7/11 シナリオで両側早期終了が明確な省計算側の勝ちを持つ。

ただし、これは無条件の勝利ではない。両側早期終了はラベル出力率を下げ、低信頼画像を早期棄却することで計算量を下げる方式である。
したがって勝ち筋は、「全画像へラベルを付ける分類」ではなく、「信頼できるラベルだけを低コストで出したい検品・低品質入力混入」の条件である。

## 発表で使える主張

両側早期終了は、既存の上側早期終了のように「自信があるものを早く出す」だけではなく、
「後段まで進めても信頼ラベルになりにくい低品質入力を早く棄却する」点で差別化できる。
今回の低品質混入条件では、上側早期終了のみは99%級の精度制約を満たす有効設定が見つからず、
両側早期終了だけが精度を保ちながらfinal実行率を下げる設定を持った。

## 注意

良品ロス5%級の設定は省計算効果が大きいが、棄却による損失も大きい。
修論の主張では、良品ロス1%級または2%級でも十分な削減がある条件を中心に扱う方が安全である。
