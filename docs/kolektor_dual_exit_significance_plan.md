# 提案システムの有意性を示す実験計画

## 目的

提案する両側早期終了が、単に「不安な画像を捨てるから速い」だけではなく、同じ検品制約の下で既存方式より有利かを確認する。

## 比較対象

1. final-only selective classification
   - 全画像をfinalまで実行する
   - finalの欠陥確率しきい値で通過/棄却を決める

2. 通常BranchyNet
   - 早い出口で「正常と強く言える」ものだけ通過させる
   - 不安なものは後段へ送る
   - 下側の早期棄却はしない

3. 提案手法: 両側早期終了
   - 早い出口で「正常と強く言える」ものは通過
   - 早い出口で「後段でも正常通過に戻らなさそう」なものは棄却
   - それ以外だけ後段へ送る

## 固定する条件

しきい値はvalidationで決め、evaluationでは固定して使う。

制約:

- 欠陥誤通過率: 0%または10%以下
- 正常品通過率: 95%または98%以上

この制約を満たす中で、平均計算量が最小の設定を選ぶ。

## 見たい結論

提案手法が有意と言えるのは、次の条件を満たす場合である。

- final-onlyより平均計算量が小さい
- 通常BranchyNetより平均計算量が小さい
- 欠陥誤通過率と正常品通過率の制約を破らない

これが出れば、「品質制約を固定したまま、後段実行をさらに削れる」という主張になる。

逆に、通常BranchyNetやfinal-onlyと差が出なければ、両側早期終了の価値は少なくともKolektorSDD上では弱いと判断する。
