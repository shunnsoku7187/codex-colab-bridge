# PatchCore FPGA 実装前実験の完了判定

Date: 2026-08-23

## 結論

カテゴリ別プロファイル型PatchCore-liteとしてFPGA実装へ進む。初回ターゲットはhazelnut、wood/cable/zipperは比較・バックアップ候補にする。

ここから先の主要な未確認事項は、GPU上の追加探索ではなく、FPGA実装で実測するべき項目です。

## 実装前に確認できたこと

| 確認項目 | 判定 | 根拠 |
|---|---:|---|
| 小さいPatchCoreバンク/探索で本当に計算を減らせるか | 完了 | mean NN ops 0.0109x, median 0.0035x |
| 98%級のKNN削減は単なる測定ノイズではないか | 完了 | 演算回数、バンクサイズ、探索時間の監査が同じ方向を示した。 |
| 全カテゴリ共通の軽量設定で十分か | 否定的 | 共通設定ではカテゴリ依存の良品通過低下が出る。カテゴリ別プロファイルの方が筋が良い。 |
| 15カテゴリすべてで厳しい検品品質を満たせるか | 否定的 | 欠陥誤通過 <= 3% を満たすのは 5/15 カテゴリのみ。 |
| モード切替構造に技術的な意味はあるか | 完了 | 全カテゴリ分バンクが 131.660 MiB -> 3.288 MiB。 |

## 主要な数値

| 項目 | 結果 | 読み取り |
|---|---:|---|
| カテゴリ別プロファイルのholdout評価 | 良品通過 54.59%, 欠陥誤通過 4.56%, KNN 0.0206x | 計算削減は再現するが、全カテゴリで安全とは言えない。 |
| FPGA向け総コスト近似 | 平均 0.2687x, 中央値 0.2035x | CNNとKNNを合わせても大きく下がる。 |
| KNN探索コスト | 平均 0.0109x, 中央値 0.0035x | 98%級の削減は演算回数の見積もりとして成立している。 |
| 全カテゴリ分のメモリバンク | 131.660 MiB -> 3.288 MiB | カテゴリ別バンクにより常駐メモリを 97.50% 削減できる。 |
| 512並列距離計算器モデル | 平均 0.193 ms, 最大 1.470 ms | 削減後バンクはFPGA上の並列KNNに載せる候補として現実的。 |

## 全カテゴリ共通設定との比較

ここが研究テーマの芯です。単にPatchCoreを小型化するのではなく、検品対象ごとに必要な構成だけを使う。

| 設定 | 良品通過 | KNN演算 | コメント |
|---|---:|---:|---|
| 全カテゴリ共通: 基準構成 (`wrn_l23_g14_b12000`) | 59.34% | 1.0000x | 最も重い参照点。 |
| 全カテゴリ共通: 良品通過最大 (`wrn_l23_g14_b12000`) | 59.34% | 1.0000x | 良品通過を最大化すると基準構成から小さくならない。 |
| 全カテゴリ共通: KNN 20%以下 (`wrn_l3_g14_b3000`) | 57.19% | 0.1667x | 共通軽量化で品質を残せる限界の目安。 |
| 全カテゴリ共通: KNN 10%以下 (`wrn_l23_g14_b1000`) | 44.88% | 0.0834x | さらに軽くすると良品通過が大きく下がる。 |
| カテゴリ別選択設定、holdout平均 | 54.59% | 0.0206x | KNNは非常に小さいが、安全性はカテゴリ別に扱う必要がある。 |

## 品質面の限界

MVTec ADの15カテゴリに対して、選択済みプロファイル設定が欠陥誤通過 <= 1% を満たしたのは 0/15 カテゴリ、<= 3% は 5/15 カテゴリ、<= 5% は 9/15 カテゴリでした。

したがって、現時点で主張できるのは「全カテゴリ共通の完成検品器」ではなく、「カテゴリを定めた検品対象に対して、必要なPatchCore構成を事前に決めてFPGA資源へ落とす方式」です。

## 実装前に広げない項目

| 項目 | 判定 | 理由 |
|---|---|---|
| 広いGPU探索の追加 | いったん停止 | 初回FPGAターゲットは大きく変わりにくく、現在のボトルネックは実装して実測差を見ること。 |
| 全カテゴリでの安全な完成検品器という主張 | 現時点では不可 | holdoutでの欠陥誤通過がカテゴリごとに大きく異なる。 |
| 正確な電力・実行時間 | 実装評価へ回す | 実際のデータパス、メモリ配置、クロック、合成・配置配線が必要。 |
| 固定小数点/int8での品質保証 | 実装受け入れ試験へ回す | バンク削減率はビット幅に依存しないが、スコア変動は採用する数値形式で決まる。 |
| 新規データセット追加 | スコープ拡大時のみ | MVTec ADで15種類の工業検品カテゴリを扱えており、次に欠けている証拠はハードウェア実測。 |

## FPGA実装へ入る条件

- まず1カテゴリの特徴抽出・メモリバンク・距離計算構成を実装する。
- 欠陥誤通過と良品通過を分けて報告し、AUROCだけで品質低下を隠さない。
- 総コスト近似と実際のFPGA遅延・資源量・電力の差を測る。
- その後、単一カテゴリ実装からモード切替型の複数カテゴリ対応へ拡張する。
