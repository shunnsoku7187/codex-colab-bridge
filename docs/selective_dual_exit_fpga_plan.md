# Selective Classification / 両側早期終了のFPGA化 計画

## 目的

研究テーマを次の二軸で進める。

1. 両側早期終了の有意性を実験データで示す。
2. Selective Classificationを再現し、FPGA実装で何を変える必要があるかを評価する。

ここでいう「有意性」は、単に平均計算量が下がることではない。検品や信頼性重視の画像認識では、全画像に必ずラベルを付けるよりも、「信頼できるラベルだけを出し、危ないものは出さない」ことが重要になる。この条件で、同じ信頼性を保ちながら、どこまで計算量・遅延・電力を下げられるかを評価する。

## 用語の定義

- ラベル出力率: 全入力のうち、システムがクラスラベルを出した割合。Selective Classificationでは coverage と呼ばれる。
- 選択後誤り率: ラベルを出した画像だけを対象にした誤分類率。Selective risk と呼ばれる。
- 信頼ラベル: あらかじめ定めた選択後誤り率以下で出せるラベル。
- 棄却: ラベルを出さない判断。検品タスクでは、良品通過ではなく排出・再検査・人手確認などの追加コストを伴う扱いにする。
- 上側早期終了: 早い出口で十分に高い自己確信度が出たとき、そこでラベルを出して後段を省略する方式。
- 下側早期終了: 早い出口で自己確信度が低すぎるとき、後段に進んでも信頼ラベルになる見込みが低いとして、そこで棄却して後段を省略する方式。
- 両側早期終了: 上側早期終了と下側早期終了を同じ出口に持たせる方式。

## 軸1: 両側早期終了の有意性を示す実験

### 何を証明したいか

両側早期終了が成立するには、次の関係を示す必要がある。

- 早い出口で高確信度の画像は、早くラベルを出しても誤りが少ない。
- 早い出口で低確信度の画像は、後段まで進めても信頼ラベルに復帰しにくい。
- その低確信度画像を早く棄却すると、信頼ラベルの精度を保ったまま平均計算量を下げられる。

### 比較対象

1. finalのみ: 全画像を最後まで実行し、finalの自己確信度が閾値以上のものだけラベルを出す。
2. 上側早期終了のみ: 高確信度なら途中でラベルを出し、それ以外は後段へ送る。
3. 両側早期終了: 高確信度なら途中でラベルを出し、低確信度なら途中で棄却し、中間だけ後段へ送る。

### 評価指標

- ラベル出力率
- 選択後誤り率
- 平均正規化計算量
- 後段実行率
- 早期ラベル出力率
- 早期棄却率
- finalなら正しく信頼ラベルを出せた画像を、途中で棄却してしまった割合

最後の指標を入れる理由は、単に大量に棄却して計算量を下げる逃げを防ぐためである。

### 既存結果から見えていること

きれいなCIFAR-10だけでは、finalの自己確信度で選ぶSelective Classificationが強い。今回の監査では、ラベル出力率70%でfinalのみの選択後精度は約98.86%、ラベル出力率55%では約99.56%だった。一方、同じリスク条件で両側早期終了が計算量を大きく下げられる点は、きれいな入力だけではまだ弱い。

ただし、低品質入力を混ぜた既存実験では方向性が出ている。例えば clean75_occlude16_25 条件では、99%級の信頼ラベルを保ちながら、両側早期終了で平均計算量を約0.875、0.778、0.655まで下げる設定が見つかっている。この結果は、両側早期終了の勝ち筋が「通常画像の高速化」ではなく、「ノイズや遮蔽が混じる入力から信頼ラベルだけを拾う」条件にあることを示している。

### 次に行う実験

1. 低品質入力の種類を増やす。
   - blur
   - occlusion
   - brightness shift
   - contrast shift
   - gaussian noise
   - JPEG劣化
2. 各条件で、finalのみ・上側早期終了・両側早期終了のリスク-計算量曲線を出す。
3. 「信頼ラベルをどれだけ残すか」と「平均計算量をどれだけ下げるか」のトレードオフ曲線を作る。
4. 途中出口の低確信度帯ごとに、finalで信頼ラベルへ復帰する割合を可視化する。

## 軸2: Selective Classificationの再現とFPGA化

### まず再現するもの

最初にSoftmax ResponseによるSelective Classificationを再現する。

Softmax Responseとは、モデルの最大softmax値が高い順にラベルを出す単純な基準である。学習済みモデルを変えずに使えるため、Selective Classificationの最小基準として扱う。

次にSelectiveNet型の再現を行う。SelectiveNetは、通常の分類出力とは別に「この入力へラベルを出してよいか」を学習する選択ヘッドを持つ。目標ラベル出力率を制約として与え、選択後誤り率を下げる方向に学習する。

### FPGA実装で変わること

| 方式 | モデル変更 | FPGAで追加されるもの | 良い影響 | 悪い影響 |
|---|---|---|---|---|
| Softmax Response | なし | 最大値計算と閾値比較 | 実装が軽い、既存モデルに後付け可能 | 選択性能はモデルの自己確信度に依存 |
| SelectiveNet | 選択ヘッド追加 | 選択ヘッド、制約付き学習、閾値制御 | 同じラベル出力率で誤り率を下げられる可能性 | 追加回路と再学習が必要 |
| 両側早期終了 | 途中出口と上下閾値 | 出口ごとの比較器、制御FSM、後段のenable制御 | 後段実行回数を減らせる | 誤棄却、閾値調整、分岐制御が難しい |

### FPGA化で評価すべき指標

- LUT / FF / DSP / BRAM
- 最大動作周波数
- 1画像あたりの最悪遅延
- 1画像あたりの平均遅延
- スループット
- 平均消費電力
- ラベル1件あたりのエネルギー
- 棄却1件あたりに使ったエネルギー
- 後段を止めたことによる動的電力削減量

### FPGA化で主張できる可能性

Selective Classificationはソフトウェア上では「信頼できるものだけ答える」枠組みである。FPGA化では、それに加えて「答えないと決めた入力に対して、後段回路を実際に動かさない」ことができる。このため、単なる選択精度だけでなく、棄却判断と省電力を直結させられる。

両側早期終了は、Selective Classificationの棄却判断を途中出口へ移す方式と見なせる。つまり、finalで棄却するだけの方式に対して、「棄却される可能性が高い入力を早く止める」ことができるかを問う研究になる。
